Waveform options

Why the current one reads as a chart

It reads as a chart because it is one. The strip on the cards today is a spectrum analyser, so its horizontal axis is frequency, running from 40 Hz on the left to 11 kHz on the right. Every bar is a different pitch band. An audio waveform puts time on that axis instead. That is the whole difference, and it is why the eye wants to read the current strip as data about the episode rather than as the sound.

A second, smaller thing: the bars grow upward from a baseline, which is the bar chart idiom. Waveforms are drawn symmetrically about a centre line.

The options below all run off the same audio at the same time, so they can be compared directly. Press play, then judge them at the heights and widths the real cards use: 12 is design B, 16 is design A, 24 is design C.

1. Mirrored spectrumsmallest possible change

The same bars and the same data, drawn symmetrically about the centre line instead of standing on a baseline. This fixes the idiom without touching anything else, so it is the cheapest option by a distance. It does not fix the axis: this is still frequency across the width, so it still is not really a waveform.

2. Oscilloscopethe literal waveform

A single continuous line tracing the actual pressure wave, about 20 ms of it at a time. This is what a waveform literally is, and nobody mistakes it for a chart. It is also the busiest of the options and the least legible at 12px tall, because the detail it draws is real rather than smoothed.

3. Scrolling barsthe voice memo idiom

One bar per moment, newest on the right, the history sliding left as it plays. Time on the x axis and visibly moving, so it reads as sound happening now rather than as a summary of anything. The strongest cure for the chart reading, and the one that most says "this is live".

4. Scrolling envelopeoption 3, softened

The same data as option 3 drawn as one smooth filled shape rather than discrete bars. Quieter and more decorative, and it survives small heights better than the bars do because there are no gaps to lose.

5. The two crossing strokesalready drawn, frame 2600:136700

The wave from the Audio Widgets file, driven by the audio: the lower band moves one curve and everything above 500 Hz moves the other, so the two cross differently as the sound changes. Decorative rather than informative, which is the point. It is the only option here that is a drawing first and a reading of the audio second, so it never reads as data, but it also tells you the least.

Not built, and why

The whole episode waveform with a played and unplayed split, the one SoundCloud draws. It is a genuine waveform and the shape most listeners have seen, but it needs the entire file decoded before it can be drawn, which an embed cannot do at load. It also spans the full width as a fixed silhouette, which is exactly the thing that makes the current strip read as a summary of the episode. Worth doing if you want it, but it fights the brief rather than answering it.
